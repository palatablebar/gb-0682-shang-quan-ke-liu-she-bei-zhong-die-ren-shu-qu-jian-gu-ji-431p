# 客流观测与区间

区域人数与两两交集必须是非负整数，单位人或千人。东门、中庭、西门映射为A、B、C。时间先转UTC后形成小时桶；非整点观测向下归入所在UTC小时桶。同一观测按version选择最高版，矛盾同版隔离。

最多三个区域。两区域无交集观测时联合人数为[max(A,B),A+B]；已知交集I时为A+B-I。三区域需要全部两两交集。三方交集T下界为max(0,AB+AC-A,AB+BC-B,AC+BC-C)，上界为min(AB,AC,BC)。联合人数为A+B+C-AB-AC-BC+T。区间无可行整数时整桶隔离。输出上下界，不估算未经观测的精确人数。日汇总是分桶客次的上下界相加，不宣称是全天独立人数。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

三方交集仅在A、B、C三个区域齐全时适用，类型triple的left必须为ABC，right必须为空。

支持区域固定为A、B、C；其他区域标识拒绝，防止三方ABC记录关联到另一组区域。

## 闸机日结总量的定性（裁决）

闸机日结总量是单点观测，**只作佐证（adjudication=EVIDENCE），不是正式约束**。正式结果始终是满足全部区域交集约束的客次区间，闸机总量不收窄、不替代它：

- 未提供 `gate_total`：状态 `WITHOUT_GATE`，只按区间出正式结果。
- 总量落在区间内（含边界）：状态 `GATE_MATCH`，标记“佐证一致”，偏差记 0；区间仍是唯一正式结果，不输出单点精确值。
- 总量越出区间：状态 `GATE_MISMATCH`，总量与区间两份证据同时保留，偏差按越界方向记录，批次转**待核对**（`reconcile.pending=true`），不封存、不可复核通过，直到矛盾解除。

`gate_total` 经参数 `parameters.gate_total` 传入，必须是非负整数；非法值返回 GATE 错误。对账页面（M6）与封存资料（M7）对同一批次采用完全相同的判断。

## 小时补录与重算边界

补录经 `POST /api/runs/<run_id>/supplement` 提交带原表头的CSV。系统合并原字节与补录行后全量重算，但只接受补录行经时区归整后所在UTC小时桶（`supplement.affected_buckets`）的变化；任何未受影响桶与原批次结果不一致都以 RECOMPUTE 拒绝，失败在落库前抛出，旧批次原样保留、记录不丢失。补录产生新 run_id（输入字节变化），但同输入同参数同规则的重跑幂等，不新增对账版本、不改复核结论。封存切换先在事务内落新批次并校验记录守恒（输入行、隔离证据、小时计算证据不得减少），再切换 latest 指针；切换失败保留旧版。
